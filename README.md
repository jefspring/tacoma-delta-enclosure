# DELTA 2 Max Enclosure — Build Spec

Marine plywood enclosure design for an EcoFlow DELTA 2 Max living in the bed of a
2013 Toyota Tacoma under a rooftop tent.

Interactive 3D model plus full build specification: dimensions, cut list, ventilation calculation, convertible sealed/ventilated shutter design, foam selection and an exact sealant schedule.

**Rev E** — verified against photographs of the actual unit. Screen and controls on one short end, AC sockets and inputs on the other, the long faces are the unit's own ventilation. Passive intake slots low on both long walls, single lid exhaust fan under a rain cap, fixed acrylic window with sealed boot-plungers, fully removable lid.
