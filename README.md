# DELTA 2 Max Enclosure — Build Spec

Marine plywood enclosure design for an EcoFlow DELTA 2 Max living in the bed of a
2013 Toyota Tacoma under a rooftop tent.

Interactive 3D model plus full build specification: dimensions, cut list,
ventilation calculation, convertible sealed/ventilated shutter design, foam
selection and an exact sealant schedule.

**Live page:** https://jefspring.github.io/tacoma-delta-enclosure/

Single static `index.html`. Three.js r181 loaded from unpkg via importmap.
